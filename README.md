# EduAdvisor — AI-Powered Academic Advising Assistant

> Answers student questions about courses, prerequisites, and graduation

> requirements, grounded in official university PDF documents.

## Problem Statement
Students struggle to get timely, accurate academic advice. Advisors are overloaded.
EduAdvisor provides instant, document-grounded answers 24/7.

## Target Users
Undergraduate students planning course registration and graduation.

## Data Sources
- Course Catalogue PDF (university website)
- Student Handbook PDF (university website)
- Graduation Requirements PDF (faculty office)
